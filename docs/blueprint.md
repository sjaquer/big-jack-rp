# **App Name**: Big Jack Manager

## Core Features:

- Registro de Productos: Registra y gestiona todos los productos, incluyendo nombre, SKU, ingredientes, precios, precio de venta, proveedor, fecha de compra, y otros detalles para un inventario completo.
- Seguimiento de Ingredientes: Realiza un seguimiento del uso de ingredientes, el gramaje por producto, el costo por ingrediente y la cantidad restante en inventario.
- Gestión de Inventario: Supervisa los niveles de inventario de productos, ingredientes y otros artículos (cajas, pegatinas, bolsas). Incluye el seguimiento de la fecha de vencimiento, la gestión del inventario basada en la posición y alertas de stock mínimo.
- Punto de Venta (POS): Procesa transacciones en soles peruanos, calcula el cambio e imprime recibos.
- Panel de Informes de Ventas: Muestra los datos de ventas diarias con visualizaciones, incluyendo los ingresos totales, los artículos más populares y el beneficio neto.
- Predicción de Efectivo: Utiliza la IA como herramienta para predecir los niveles de efectivo esperados en soles peruanos para procedimientos eficientes de cierre y apertura.
- Gestión de Pedidos en Línea: Recibe y gestiona los pedidos en línea del sitio web externo a través de endpoints de la API, proporcionando una sección para gestionar el estado y la preparación de los pedidos.

## Style Guidelines:

- Color primario: Rojo saturado y vibrante (#D73D1D) para evocar la energía de una hamburguesería.
- Color de fondo: Rojo claro desaturado (#FFD4A1), complementando el primario manteniendo la interfaz de usuario limpia.
- Color de acento: Negro (#020204) para resaltar acciones importantes y botones de llamada a la acción.
- Fuente del título: 'Poppins', sans-serif, para una sensación moderna y a la moda.
- Fuente del cuerpo: 'PT Sans', sans-serif, para asegurar la legibilidad en todo el panel.
- Utiliza iconos claros y audaces para el reconocimiento rápido de productos y acciones dentro de la interfaz.
- Mantén un diseño limpio y estructurado, haciendo que la información sea fácilmente accesible y escaneable.
- Animaciones sutiles para actualizaciones de datos y transiciones para proporcionar retroalimentación y compromiso.
